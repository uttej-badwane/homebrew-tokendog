# homebrew-tokendog

Homebrew tap for [TokenDog](https://github.com/uttej-badwane/TokenDog), a token-optimized CLI proxy for AI coding assistants.

## Install

```sh
brew install uttej-badwane/tokendog/tokendog
```

This installs the `td` command (also available as `tokendog`) on macOS and Linux.

## Formula → cask migration

TokenDog is published as a **cask** (`Casks/tokendog.rb`), generated by GoReleaser on each release. It used to be a formula; `tap_migrations.json` moves existing installs over:

- **Tap trusted** (`brew trust --tap uttej-badwane/tokendog`): `brew update` unlinks the old formula and installs the cask automatically. Remove the leftover formula afterwards with `brew uninstall --formula --force tokendog`.
- **Tap not trusted**: `brew update` prints the commands to finish the migration:
  ```sh
  brew trust --cask uttej-badwane/tokendog/tokendog
  brew install --cask uttej-badwane/tokendog/tokendog
  ```

Don't edit `Casks/tokendog.rb` by hand; it is regenerated on every release.
